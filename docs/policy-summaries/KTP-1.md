# 상담사용 병원 탐색·진료 연결 — 협의용 시안

**PRD ID:** `KTP-1`

이 문서는 공개 시안에 필요한 최소 흐름만 요약합니다. 실제 서비스·법률 문안·계정 보안·배포 일정은 확정된 구현이 아닙니다.

| 화면 | 시안에서 확인하는 흐름 |
|---|---|
| 병원 검색·지도 | 병원 전화번호 즉시 표시. 지도는 개발 산정에 따라 1차 제외 가능 |
| 진료 신청 패널 | 환자 조회 동의 확인 → 기본정보 조회 → 진료실·목적·일시 선택 |
| 고객 확인 | 알림톡·문자 링크 → 고객 직접 7자리 입력과 동의 → 상담사에게 완료 상태만 표시 |
| 재전송 | 고객 요청 시 이전 링크·입력 폐기 후 재입력. 1차 제외 가능 |
| 최종 신청 | 상담사 최종 신청 후 병원 응답 대기. 전달 완료와 예약 확정 구분 |
| 결과 알림 | 예약 확정·병원 취소·실제 진료 완료. 리마인더 제외 |
| 고객 취소 경로 | 예약 확정 안내에서 앱의 해당 예약으로 연결·취소하는 경로 예시 |
| 종료 | 진행 중 닫기 확인 후 임시 입력 폐기. 이미 신청된 예약 취소와 구분 |

모든 데이터와 메시지는 가상입니다. 주민번호를 저장·전달하거나 실제 메시지·예약을 생성하지 않습니다. 비급여·진료항목 정보는 탐색 전용이며 직접 신청하지 않습니다.
