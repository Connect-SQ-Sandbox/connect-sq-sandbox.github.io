# 굿닥 데스크 통합 시안

- 상태: 미승인 기획 검토용 / 2026-10-01.
- 공개 체험: https://connect-sq-sandbox.github.io/out/desk-unified.html
- 기본 진입에서는 안내만 표시하고, ‘통합 데스크 시안 열기’를 누르면 체험한다.

| 영역 | 체험 범위 |
|---|---|
| 프로그램 메뉴 | 최소화·최대화·닫기 바로 왼쪽. 환경 설정·연결 진단·프로그램 정보 |
| 병원 업무 | 홈·접수·예약 통합 조회·검색·필터·상세 |
| 연결 끊김 | 굿닥에 신청만 저장하고 차트 전달 결과는 별도로 표시 |
| 복구 | 취소·시간 만료 건 제외. 성공 응답 예시 후에만 처리 확인 |
| 서버 끊김 | 저장·상태 변경 차단 |
| 미연동 | 차트 전달 액션 비노출 |

WinUI 창 동작을 브라우저에서 모사한 웹 시안이다. 실제 WinUI 앱·인증·차트 통신·DLL 설치·주민번호 입력 또는 저장은 구현하지 않는다. 가상 데이터는 메모리에서만 관리하며 새로고침하면 초기화된다.

## 빌드

```bash
npm run proto:validate
npm run proto:share -- pages/connect/desk-unified/index.page.tsx --out desk-unified --title "굿닥 데스크 통합 시안"
```

서버/백엔드 배포: N/A. 실제 서비스의 정책 승인이나 출시를 의미하지 않는다.
