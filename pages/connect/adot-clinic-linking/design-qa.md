## 동작 검증

- 검색어 `서울` 입력 시 `서울(서울특별시)`을 지역 그룹 첫 항목으로 노출
- 검색어 `서` 입력 시 지역 그룹 뒤 진료항목 그룹에 `서바릭스 2가` 노출
- 검색어 `내` 입력 시 진료과 → 진료항목 → 병원 그룹 순서로 노출
- 검색어 `굿닥` 입력 시 병원명 자동완성 노출, 선택 시 해당 병원 목록·지도 카드 동기화
- `서바릭스 2가` 선택 시 진료항목 필터에 반영되고 보유 병원 1개 노출
- 검색어 `HPV` 입력 시 `HPV 접종(중분류)`과 `가다실 9가(소분류)` 추천 노출
- 중분류 선택 시 하위 진료항목을 하나 이상 보유한 병원만 조회
- 진료과 `내과` 선택 시 결과 1개 노출
- 지역 `서울 마포구 망원동` 선택 시 결과 3개 노출
- `굿닥 예약 가능` 필터 적용 시 4개 가상 병원 노출
- 지역·진료과·진료항목 선택창은 서로 중복되지 않으며 닫기·재선택 가능
- 필터로 선택 병원이 제외되면 지도 선택 카드도 함께 숨김
- 비예약 병원에는 별도 배지를 노출하지 않음
- 검색 태그와 진료항목을 병원 탐색에서 함께 사용하되, 신청 가능한 진료 목적에는 실제 진료항목만 사용
- 예약 설정이 있으나 잔여 슬롯이 없는 병원은 별도 빈 상태를 표시하고 제출 버튼 비활성화
- 신청 시 선택한 시간 `15:30`이 완료 화면까지 유지됨
- 연결 이력 목록 → 상세, 상담사 정보 → 로그아웃 → 로그인 화면 이동 확인
- 지도 확대·축소·현재 위치 초기화, 팝오버 `Escape` 닫기 확인
- DOM 기준 지도 배경 이미지 수 `1`, 원본 해상도 `1024 × 1024` 확인

## 비교 이력

1. 첫 비교에서 기존 8개 타일을 4열 × 2행으로 이어 붙인 경계가 지도에서 단절되어 보이는 P1 문제를 확인했다.
2. 실제 지리적 연결 순서에 맞춰 상단 지역 4개 타일을 2열 × 2행으로 재배치하고, 단일 래스터 이미지로 합성했다.
3. 수정 후 1440 × 900 기본 상태와 확대 상태를 다시 확인했으며 도로·강·지하철선이 끊김 없이 이어지고 추가 P0/P1/P2 문제는 없었다.
4. 굿닥 병원 찾기 기본·지역 선택·진료과 선택 화면과 프로토타입을 각각 동일 배율로 나란히 비교했다.
5. 굿닥의 시각 구조는 유지하되, 상담사에게 의미가 없는 현재 위치 기능은 `상담 대상 지역` 선택으로 치환했다.
6. 수정 후 검색 패널 높이는 188px, 결과 영역은 500px / 780px으로 확인했으며 가로 오버플로는 발생하지 않았다.
7. 굿닥 운영 웹과 동일하게 지역·진료과·진료항목·병원 후보를 한 검색창에서 제안하되, 상담사 탐색 목적에 맞춰 그룹 우선순위는 `지역 → 진료과 → 진료항목 → 병원`으로 적용했다.
8. 실제 굿닥 검색 API는 후보군을 별도 배열로 제공하므로, 그룹 병합 순서와 영역별 노출 개수는 외부 연동 계약에서 확정할 정책 항목으로 남겼다.
