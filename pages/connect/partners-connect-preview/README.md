# 4.2 커넥트 웹뷰 · 피드백 미리보기

HAU-1 / 0.9-draft / 미승인 시안 / 릴리스일 미확정.

- 현재 화면은 테스트 사이트의 DEV 샘플 데이터 화면을 참조했다. 실제 Desk·Connect 배포 기능에 대한 검증 자료가 아니다.
- source CSS·DOM·아이콘·폰트는 캡처한 자산을 로컬 인라인으로 복사했다. 원본 앱 JavaScript·인증 코드는 복사하지 않았다.
- **2026-10-08 사용자 보완:** 제품키로 확인한 병원 권한의 커넥트 웹뷰를 보여준다. 공유용 시안에서 파트너스 상단 네비게이션 전체를 제거했다. 미리보기 토글은 제품 메뉴가 아니라 비교 도구다.
- 현재/통합, 연동/비연동 병원 유형을 비교한다. 변경 예정 화면은 기본 OFF이며, 켜면 검토용 안내를 표시한다.
- 접수·진료실 예약은 연동 병원 조회만 / 비연동 병원 기존 상태 처리. 환자는 조회만. 진료 항목 예약은 별도 권한 검토를 명시했다.
- 새 메뉴 이름·묶음은 피드백용 제안이다. 확정 정책·실제 서비스 권한 변경이 아니다.
- 원본의 DEV/실패 재현용 도구는 제외했다. 접수·예약·환자·진료실 및 기존 진료 항목 입력 화면은 원본 클래스와 레이아웃을 유지했다.
- 검색·상세·메뉴 전환·설정 ON/OFF는 화면에서 체험한다. 상태 변경 버튼은 눌러볼 수 있지만 실제 저장·알림은 하지 않는다. 환자정보 복사·파일 업로드·제품키 변경·실제 삭제는 실행하지 않는다.
- 원본 사이트·기존 샌드박스 시안은 수정하지 않았다. 내부 문서·피드백 시트 주소를 공개 HTML에 넣지 않았다.
- 백엔드 배포: 해당 없음. 서버 호출이 없는 독립 정적 HTML만 배포한다.
