신청 웹 · 독감 무료접종 대상자 선택 UX신규
환자가 무료 백신 대상자(임신부·어린이·어르신)로 신청할 때의 독립된 결정 2건을 각각 비교하는 보드입니다. 상단 이슈 세그먼트로 갈라 보며, 안은 이슈당 3개, 총 6개로 추렸습니다. 채택안은 둘 다 아직 정해지지 않았습니다.
  • 이슈 ① 하위 뎁스 처리 — 대상자를 고른 뒤 주성분·독감백신 종류를 어떻게 처리할지 3안. A~C는 추천 순위입니다: A 하위 뎁스 접기 · B 읽기 전용 행 · C 비활성. 상태 ①대상자 선택 전 ②해당 없음 ③어린이 + 예약 정보 확인 카드까지 나란히 놓고 비교하며, 아래 표는 탭 수·허위 선택 인상 위험·레이아웃 흔들림·설명 텍스트 필요량·기존 컴포넌트 재사용도 5축.
  • 실제 동작(기본 진입) — 상단 안 세그먼트로 A~C를, 진료 대상자 세그먼트로 F-1~F-3을 바꿔 가며 화면을 직접 눌러봅니다. 대상자를 고르면 제품·금액이 병원 상담 후 결정 · 미정으로 넘어가고, 판정·서류·인증 UI 없이 고지 문구로만 처리합니다.
  • 이슈 ② 진료 대상자 — 예약자 본인이 아닌 사람의 접종을 신청하는 경우를 언제·어떻게 물을지 3안. F-1 체크박스 비활성은 생년월일을 대조해 불일치를 오류로 다루는 방식(비교 기준으로 보존)이고, F-2 대상자 선택 화면 통합형 · F-3 신청서 섹션 재설계형은 대조를 버리고 본인/대리 여부를 먼저 묻는 방식입니다(어린이·영유아는 부모의 대리 예약이 기본 케이스).

진료항목 어드민 · 분류 선택 트리판신규
분류 선택을 모달에서 꺼내 폼 안에 3열 트리로 놓은 버전입니다.
  • 트리 — 대분류 → 중분류 → 소분류 순으로 좁혀 갑니다. 처음엔 추천 항목(독감 9종)이 열려 있고, 기타는 대분류에서 빼고 중·소분류에만 뒀습니다.
  • 검색 — 결과를 레이어로 띄웁니다. 고르면 아래 트리의 세 열도 그 경로로 따라 이동합니다.
  • 스펙 보기(우측 상단, 기본 켜짐) — 영역마다 ⓘ 가 붙고, 누르면 그 영역의 정책이 패널로 뜹니다. 피그마 디스크립션을 프로토타입 안으로 옮긴 핸드오프 실험입니다.
  • 예약 신청 내역 — 제품을 특정하지 않고 들어온 독감 무료접종 건이 목록·상세에 어떻게 보이는지 함께 담았습니다.
