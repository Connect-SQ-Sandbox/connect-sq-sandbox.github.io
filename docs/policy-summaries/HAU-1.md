# 커넥트 웹뷰 통합 · 검토용 미리보기

**PRD ID:** `HAU-1`

미승인 검토용 시안입니다. 실제 병원·환자 데이터, 서버, 차트, 설치 기능은 연결하지 않습니다.

## 현재 범위의 미리보기

- 기존 데스크의 업무 메뉴와 화면을 커넥트 웹뷰로 옮기는 범위입니다. 진료 항목은 기존 기능을 유지합니다.
- 제품키로 병원 권한이 확인된 웹뷰를 가정합니다. 파트너스 로그인·상단 네비게이션은 표시하지 않습니다. 실제 제품키 인증은 구현하지 않습니다.
- 접수·진료실 예약 상태 처리는 비연동 병원만 가능하고 연동 병원은 조회만 합니다. 연결 장애가 생겨도 비연동 권한으로 바뀌지 않습니다.
- 비연동 병원은 진료실을 관리하고, 연동 병원은 차트 진료실을 조회합니다. 서비스와 연결된 진료실의 삭제 조건은 검토 중입니다.
- 환자는 조회만 제공하며 주민번호 뒷자리는 가립니다. 접수·예약·환자의 직접 추가·수정·삭제는 이번 범위에서 제외합니다.
- 진료 항목 예약의 연동 병원 처리 권한은 별도 검토 대상으로 표시합니다.
- PC 환경 설정·OS 알림 설정은 네이티브에 유지합니다. 알림센터는 포함 후보이며 검토 후 다음 단계로 미룰 수 있습니다.
- 원본 테스트 화면의 HTML/CSS·로컬 자산을 활용하되, 저장·알림·업로드는 실행하지 않는 별도 공유용 시안입니다.

## 이전 시뮬레이터 참고 (0.5-draft 기반 · 최신 범위 아님)

- As-is는 기존 진료항목 예약·관리 메뉴를 재현합니다. To-be는 상단에서 켠 경우만 표시합니다.
- 바탕화면·작업표시줄·창 버튼으로 Windows 프로그램 외형을 모사합니다. 최소화·닫기 후 커넥트 아이콘으로 업무 화면을 복원할 수 있습니다. 실제 운영체제는 변경하지 않습니다.
- 통합안에서는 대시보드와 접수·진료실 예약·진료항목 예약을 합친 진료 현황을 확인합니다.
- 검색·필터·정렬·상세·취소 사유 입력·진료완료·내원확인을 가상 데이터로 체험합니다. 진료항목 예약에는 내원확인을 제공하지 않습니다.
- 프로그램 환경설정은 트레이에서 엽니다. 기본값은 비연동이며 차트 선택·브릿지 설치·연결 장애·복구는 화면으로만 모사합니다.
- 굿닥 처리, 차트 전달, 환자 안내 결과는 구분합니다. 차트 진료완료 전달 규격은 확인 필요로 표시하며 실제 전달을 보장하지 않습니다.
- 연결 복구만으로 이전 상태 변경을 무조건 다시 보내지 않습니다. 내원확인은 자동 재전달 없이 현재 차트 상태 확인 필요로 구분합니다.
- 대시보드는 기존 데스크의 집계 항목·공지사항 구성을 유지하는 예시입니다. 실제 집계 규격과 데이터 이관은 별도 검증 대상입니다.
- 모든 변경은 브라우저 메모리에만 유지되며 새로고침이나 초기화로 돌아갑니다. 개인 정보를 입력하지 마세요.
