# KAK-001 정책 요약 (확정 전 예정 화면)

> 이 문서는 공개 프로토타입에서 사용하는 정책 요약입니다. 원본 PRD 전체를 복제하지 않으며, 원본 정책을 독립적으로 수정하지 않습니다.
> **확정 전 검토 단계입니다.** 아래 화면과 문구는 승인 과정에서 변경될 수 있습니다.

**PRD ID:** `KAK-001`

## 목적

- 병원이 `예약 자동 확정`을 끄고 운영하더라도, 카카오톡 예약하기로 받는 예약은 자동으로 확정됩니다.
- 병원 담당자가 이 예외를 미리 알고, 실제로 적용된 예약을 화면에서 구분할 수 있게 합니다.

## 적용 범위

- 관리자 화면(Connect)만 변경합니다. 환자가 사용하는 예약 신청 화면은 변경하지 않습니다.
- 안내는 진료 예약 설정과 진료항목 상세 두 화면에만 넣습니다. 예약 신청 내역 화면은 이번 범위에서 변경하지 않습니다.
- 굿닥으로 받는 예약은 기존과 동일하게 병원의 `예약 자동 확정` 설정을 따릅니다.
- 카카오톡 예약하기에서 수동 확정이 지원되면 예외와 관련 안내를 함께 제거합니다.

## 현재 프로토타입 반영 기준

### 진료 예약 설정

- 안내는 `예약 자동 확정` 설정 항목의 **박스 안**에 넣습니다. 제목·설명·토글 한 줄 아래에 전체 폭으로 붙여, 어느 설정의 예외인지 분리된 배너보다 확실하게 읽히도록 합니다.
- 설정이 OFF(수동 확정)일 때 안내 블록을 표시합니다. 제목 `카카오톡 예약하기로 받는 예약은 자동으로 확정됩니다`와 세 개의 안내로 구성합니다. 굿닥 예약의 적용 범위, 임시 정책이라는 사실, 진료하기 어려운 예약은 예약 신청 내역에서 취소할 수 있다는 안내입니다.
- 설정이 ON일 때는 설명 아래에 한 줄만 표시합니다. 문구는 `카카오톡 예약하기로 받는 예약은 이 설정과 관계없이 자동으로 확정됩니다.`입니다. OFF일 때는 안내 블록이 같은 내용을 더 자세히 말하므로 이 한 줄은 표시하지 않습니다.
- 안내 블록은 닫을 수 없으며, 설정을 다시 ON으로 바꾸면 즉시 한 줄 안내로 바뀝니다.
- 설정을 ON에서 OFF로 바꾸는 시점에 확인 모달을 표시합니다. 진행 버튼은 `자동 확정 끄기`이며, 취소하면 설정은 ON 상태로 유지됩니다.
- 안내 톤은 오류가 아닌 주의 사항으로 처리합니다.

### 진료항목 상세

- 병원이 수동 확정으로 운영 중일 때, `카카오톡 예약하기에서도 보이기` 토글의 설명 영역에 `카카오톡 예약하기로 받는 예약은 자동으로 확정됩니다.`를 한 줄로 표시합니다. 굿닥 예약의 적용 범위는 병원 단위 이야기라 진료 예약 설정에서만 안내합니다.
- 토글을 켜는 시점에는 별도 확인 모달을 두지 않습니다. 항목을 여러 개 설정할 때 반복 확인이 되지 않도록 설명 문구로만 안내합니다.

## 문구 원칙

- 세 지점(진료항목 상세 · 진료 예약 설정 · 전환 확인 모달)이 같은 문장을 조합만 달리해 씁니다. 화면마다 표현을 바꾸지 않습니다.
- 고정 어휘 — 대상은 `카카오톡 예약하기로 받는 예약`, 대비는 `굿닥으로 받는 예약`, 병원 설정은 `수동 확정 설정`, 결과는 `자동으로 확정됩니다`입니다.
- 정보량은 화면 성격에 따릅니다. 스쳐 보는 진료항목 상세는 사실 한 문장, 결정하는 설정 화면은 전부, 전환 시점의 모달은 사실과 근거만 담습니다.

## 노출 조건

- 병원 단위 카카오톡 예약하기 연동이 `연동완료`인 경우에만 위 안내를 표시합니다. 연동대기·연동불가·연동해제·미연동 병원에는 표시하지 않습니다.
- 설정 화면에서는 자동 확정 ON이면 한 줄 안내, OFF면 설정 박스 안의 안내 블록을 표시합니다. 두 안내가 동시에 보이지는 않습니다.

## 검토가 필요한 항목

- 안내에서 카카오 노출을 끄는 경로를 함께 제공할지 여부.
- 카카오톡 예약하기 연동을 새로 신청하는 화면에도 사전 안내를 넣을지 여부.
- 이미 수동 확정으로 운영 중인 연동 병원에 배포 전 공지를 보낼지 여부.
